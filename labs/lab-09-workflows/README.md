# Lab 09 — Workflows

## Objectif

Implémenter les outils d'un workflow de release : parsing de commits conventionnels, génération de changelog et calcul de version sémantique.

## Instructions

1. Ouvre `exercise.ts` et complète les fonctions marquées `TODO`
2. Lance les tests : `npm run lab:09`
3. Vérifie avec la solution : `npm run solution:09`

## Concepts testés

- Parsing de messages Conventional Commits
- Génération de changelog structuré
- Calcul automatique de version sémantique (semver)
