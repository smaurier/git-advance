# Lab 07 — Worktrees & Submodules

## Objectif

Modéliser la gestion des worktrees Git et des submodules pour comprendre ces fonctionnalités avancées.

## Instructions

1. Ouvre `exercise.ts` et complète les fonctions marquées `TODO`
2. Lance les tests : `npm run lab:07`
3. Vérifie avec la solution : `npm run solution:07`

## Concepts testés

- Gestion de worktrees (ajout, suppression, listage)
- Détection de conflits de branche entre worktrees
- Modélisation de submodules (références à des commits externes)
