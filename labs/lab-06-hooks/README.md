# Lab 06 — Git Hooks

## Objectif

Simuler le fonctionnement des hooks Git : validation de messages de commit, vérification pré-commit et chaînes de hooks.

## Instructions

1. Ouvre `exercise.ts` et complète les fonctions marquées `TODO`
2. Lance les tests : `npm run lab:06`
3. Vérifie avec la solution : `npm run solution:06`

## Concepts testés

- Validation de messages au format Conventional Commits
- Simulation de hooks pre-commit (lint)
- Exécution en chaîne de hooks (pipeline de validation)
