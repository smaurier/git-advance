# Lab 03 — Merge vs Rebase

## Objectif

Comprendre les différences entre merge et rebase en simulant les deux opérations sur un graphe de commits.

## Instructions

1. Ouvre `exercise.ts` et complète les fonctions marquées `TODO`
2. Lance les tests : `npm run lab:03`
3. Vérifie avec la solution : `npm run solution:03`

## Concepts testés

- Détection de fast-forward
- Merge 3-way avec commit de merge
- Rebase : rejouer les commits sur une nouvelle base
- Détection de divergence entre branches
