# Lab 05 — Git Bisect

## Objectif

Implémenter l'algorithme de recherche binaire utilisé par `git bisect` pour trouver le premier commit qui a introduit un bug.

## Instructions

1. Ouvre `exercise.ts` et complète les fonctions marquées `TODO`
2. Lance les tests : `npm run lab:05`
3. Vérifie avec la solution : `npm run solution:05`

## Concepts testés

- Recherche binaire sur un tableau de commits
- Simulation du workflow bisect (good/bad)
- Bisect automatisé avec fonction de test
