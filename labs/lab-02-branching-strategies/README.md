# Lab 02 — Branching Strategies

## Objectif

Modéliser les opérations de branches Git et simuler un workflow Git Flow avec validation des conventions de nommage.

## Instructions

1. Ouvre `exercise.ts` et complète les fonctions marquées `TODO`
2. Lance les tests : `npm run lab:02`
3. Vérifie avec la solution : `npm run solution:02`

## Concepts testés

- Création, fusion et listage de branches
- Workflow Git Flow (feature, release, hotfix)
- Validation des conventions de nommage de branches
