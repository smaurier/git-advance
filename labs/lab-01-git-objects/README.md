# Lab 01 — Git Objects

## Objectif

Comprendre le modèle objet de Git en implémentant des fonctions qui simulent le stockage et la résolution d'objets Git.

## Instructions

1. Ouvre `exercise.ts` et complète les fonctions marquées `TODO`
2. Lance les tests : `npm run lab:01`
3. Vérifie avec la solution : `npm run solution:01`

## Concepts testés

- Hashing SHA-1 d'objets Git (blob, tree, commit)
- Résolution de références
- Navigation dans le graphe d'objets
